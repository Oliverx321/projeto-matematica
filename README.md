# 📊 Aplicativo de Probabilidade e Vetores

Este projeto foi desenvolvido em Python utilizando a biblioteca **Streamlit** como parte de uma atividade acadêmica de Matemática. O objetivo é fornecer uma interface web interativa para cálculos estatísticos e geométricos.

🚀 **[Clique aqui para acessar o site oficial do projeto](https://streamlit.app)**

## 🛠️ Funcionalidades

- **Módulo de Probabilidade:** Cálculo exato da Distribuição Binomial com base no número de tentativas, probabilidade de sucesso e sucesso desejado.
- **Módulo de Vetores:** Resolução de uma situação-problema prática envolvendo a navegação de um drone no espaço 2D, calculando o vetor resultante e a magnitude do deslocamento.

## 💻 Como rodar o projeto localmente

Se quiser executar este projeto na sua máquina, siga os passos abaixo:

1. Clone o repositório ou baixe os arquivos.
2. Instale as dependências necessárias:
   ```bash
   pip install streamlit numpy scipy
   ```
3. Execute o aplicativo:
   ```bash
   streamlit run app.py
   ```
